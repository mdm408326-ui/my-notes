How to add these to the website

  1. Drop all the .svg files into your site’s public/ (or src/assets/) folder.
  2. Use them like any image: <img src="/service-home.svg" alt="Home shifting">.
  3. For the favicon, in index.html: <link rel="icon" href="/favicon.svg">.
  4. For the share preview: <meta property="og:image" content="/social-share.svg"> (some platforms prefer PNG — I can export PNG copies if needed).
